\section*{About this working file}
This project follows the folder and LaTeX conventions used in
\href{https://github.com/gadepall/ee1010-2026/tree/master/EE26BTECH11202}{the EE1010 course folder}:
questions and solutions are stored in \texttt{chapters/}; plotting scripts and the
\texttt{CoordGeo} helper package are under \texttt{codes/}; generated figures are under
\texttt{figs/}; and the root document imports the style files \texttt{gvv-book.sty}
and \texttt{gvv.sty}. The figures included here are produced by Python scripts, not drawn
manually inside the LaTeX questions.

\textbf{Audit status.} The current batch includes Class X questions 1--4 from Section A, question 5 from Section B, and
Class XII Vectors questions 1--7 from the cited public transcriptions. Class X question 2 has been checked against the official marking scheme. Class XII vector
questions 1--2 retain source-wording flags and remain conditional. The Class X chord/tangent
figure has been redrawn with the official point placement and its angle derived accordingly.
